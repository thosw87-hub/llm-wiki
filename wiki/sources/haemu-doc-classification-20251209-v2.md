# 해무팀 문서 분류표 (2025-12-09, Version 2)

**한 줄 요약**: [[haemu-team]] 공유 폴더를 [[smmc]](새한선관) 절차서 체계에 맞춰 최대 5단계(절차서 → 장 → 폴더 → 하위폴더 → 세부폴더)로 분류한 엑셀 표. 시트 1개(「절차서별 폴더 분류」).

## 핵심 내용

- 최상위 분류는 절차서 11개 → [[smmc-procedures]]
- 표의 약 75%가 승무원관리 절차서(SMMC-CMP) Ch.1~19 → [[crew-management-procedure]]
- 외부심사는 DOC / ISO / MLC / TMSA 4개 폴더 → [[external-audits]]
- 선원 채용은 한국인(직급별)·외국인(매닝사별)·실습생으로 나누고, 인성·영어·선교관제 검사를 별도 관리 → [[crew-recruitment]]

## 검토 의견 (Claude)

분류표 개정 시 참고할 문제점:

- **중복**: 「장기근속자 표창」이 CMP Ch.5(3번)와 Ch.6(3번) 양쪽에 있음. Ch.5 안에서 「인수인계서」와 번호 3이 겹침.
- **오타**: `DEBRIEING` → `DEBRIEFING`
- **번호 형식 불일치**: 장 표기가 `Ch.1` / `1.` / `01.`로 혼재(AP·HLRP·OSMP는 `1.`, SIP는 `01.`). 마침표 뒤 띄어쓰기도 혼재(`1.DOC` vs `1. 선박증서`).
- **확인 필요**: `Ch.19.조근규정`의 의미 미확인. RAP·PSP는 하위 폴더가 비어 있음.
- **분류 위치 (추론)**: 「LTIF & TRCF」는 안전 지표라 승무원관리보다 위험성평가·경영층검토에 더 가까울 수 있음. 「선박증서」(DRP)와 「선원증서」(CMP)가 서로 다른 절차서에 있어 찾을 때 혼동 가능.
