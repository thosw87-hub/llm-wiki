# SMMC 절차서 체계

**정의**: [[smmc]](새한선관)의 업무 절차서 묶음. [[haemu-team]]은 이 절차서 번호를 공유 폴더의 최상위 분류로 쓴다 ([[haemu-doc-classification-20251209-v2]]).

## 절차서 목록

| 번호 | 절차서 | 코드 | 해무팀 폴더에 있는 장 |
|---|---|---|---|
| 01 | 문서기록관리 | SMMC-DRP | Ch.1 일반사항, Ch.5 외부문서 관리 |
| 02 | 부적합처리 | SMMC-NSP | Ch.5 고객 불만사항 처리 |
| 03 | 심사 | SMMC-AP | 내부심사, 외부심사 → [[external-audits]] |
| 04 | 경영층검토 | SMMC-HLRP | 육상안전관리위원회 |
| 05 | 육상직원관리 | SMMC-OSMP | 육상직원관리 바로가기 |
| 06 | 승무원관리 | SMMC-CMP | Ch.1~19 → [[crew-management-procedure]] |
| 07 | 위험성평가 | SMMC-RAP | (없음) |
| 08 | 선내점검 | SMMC-SIP | 방선보고서(방선계획서, 감독방선보고, 사고조사보고서) |
| 09 | 구매보급 | SMMC-PSP | (없음) |
| 10 | 변화관리 | SMMC-MoCP | Ch.3 변화 관리 범위 |
| 11 | 본선경리 | SMMC-ASP | Ch.5 선내 수당 |

## 설명

- 표의 장 번호는 절차서 원문의 장 번호로 보인다. 예컨대 DRP는 Ch.1 다음이 Ch.5여서, 해무팀이 관여하는 장만 폴더로 만든 것으로 추정한다 (추론).
- 심사 절차서에 외부심사 항목으로 DOC·ISO·MLC·TMSA가 있는 것으로 보아, 이 절차서들은 ISM Code 기반 안전관리체제(SMS) 문서로 추정한다 (추론).
